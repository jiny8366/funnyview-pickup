06 회원가입 & 약관

회원가입 (/register) — 카페24 스타일 table 폼

  • 빵부스러기 (홈 > 회원가입)
  • 소셜 가로 3개 (네이버 / 카카오 / Apple)
  • 회원구분 (개인회원) / 회원인증 (휴대폰 — 데모)
  • 기본정보: 이메일 / 아이디 / 비밀번호+확인 / 이름 / 주소 / 일반전화 / 휴대전화
  • 추가정보: 추천인 아이디 / 환불계좌
  • 약관 동의 (필수 2개 + 선택 SMS/이메일 별도)

아이디 / 비밀번호 정책

  • 아이디: /^[a-z0-9]{4,16}$/ (영문 소문자/숫자 4-16)
  • 비밀번호: 8-16자, 영문 대소/숫자/특수 중 3가지 이상 조합
  • 휴대전화: 01[016789]\d{7,8}

약관 ((주)퍼니뷰 명의)

  • [필수] 이용약관 (제1~24조 + 부칙)
  • [필수] 개인정보 수집·이용 (수집목적 / 항목 / 보유기간)
  • [선택] 쇼핑정보 수신 (SMS / 이메일 별도)
  • 전체 동의 마스터 체크박스
  • 저장: src/lib/terms.ts

09 표시명 & 바코드

표시명 (계층형, 모든 화면 통일)

{brand} / {name} / {cycle} / {pack}매 / SPH ±X.XX / CYL ±X.XX / AX XXX / ADD ±X.XX

예: 크리스틴 / 원앤온리 / 1day / 30매 / SPH -3.00

  • 단위: 팩 (=박스), 매수 환산 동시 표시 → 12팩 (360매)
  • 좌우 안: OS (좌) / OD (우) / 양안
  • 적용: picklist / inventory / order detail / pickup
  • 구현: src/lib/lens/format.ts

바코드 (1D + 2D, GTIN-13 DI 만)

  • 지원: EAN-13 / GTIN-14 / GS1-128 / GS1 DataMatrix
  • AI: (01) GTIN / (17) 유효기간 / (10) 로트 / (21) 시리얼
  • GTIN-14 → GTIN-13 자동 변환 (선두 0 제거)
  • PI (lot/expiry) 는 참고 메타데이터만 — DB 저장 X
  • 구현: src/lib/barcode/parse.ts

12 주문 & 정산

주문 흐름

4단계: 렌즈 → 도수 → 가맹점 → 결제

상태 전환

pending → paid → accepted → picking → shipped → arrived → ready → completed
                                                         ↘ cancelled
  • warehouse: accepted → picking → shipped
  • store: shipped → arrived → ready → completed
  • 5초 폴링 (재고 변동 감지)

정산

  • 월별 자동 (v_store_settlement 뷰)
  • 가맹점별 commission_rate 적용
  • 추천인 3% 리워드 (referral_rewards 테이블)

결제 (현재 mock)

  • venue: online (선결제) / store (매장 결제)
  • methods: card / cash / bank_transfer / point / mixed
  • 실 PG (Toss/Nice/PortOne) 연동은 추후
